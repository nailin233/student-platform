# 关于「只有 IPv6」的说明

如果你确认服务器**只有 IPv6、没有 IPv4**，会面临这些问题：

1. **访问不便**：IPv6 地址太长，且部分网络环境（老路由器、部分手机流量）不支持
2. **无法申请免费 SSL**：Let's Encrypt 对纯 IPv6 支持有限
3. **演示体验差**：跟客户说「打开 http://2402:4e00:c050:e00:...」不太现实

**三个可选方案**：

| 方案 | 做法 | 适合 |
|---|---|---|
| A · 申请 IPv4 | 腾讯云控制台给实例绑定弹性公网 IP | 最省事，如果实例支持 |
| B · 用免费域名 | 申请一个免费域名（如 eu.org）指向 IPv6，用域名访问 | 想练手且预算为零 |
| C · 就用 IPv6 | 接受限制，仅自己练习用 | 纯练手，不给人看 |

告诉我你的选择，或者先查清有没有 IPv4，我们再定。
